# gameplan-web

The Excalidraw canvas UI for [gameplan](https://github.com/appriai/gameplan) — Vite + React +
Excalidraw, with live cursors and an annotation palette.

This package ships only a static build (`dist/`); it's a dependency of `gameplan-server`, which
serves it, and isn't meant to be installed or run standalone.

## Learn more

Full docs and source: [github.com/appriai/gameplan](https://github.com/appriai/gameplan)
